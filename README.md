# D&D Character Generator

A single-file D&D character sheet generator and play aid based on the System Reference Document 5.2 (D&D 2024 rules).

**Features**

- Create level 1 characters: fully random, per-choice random (dice buttons), or manual selection
- All 12 SRD classes, 9 species, 4 backgrounds
- Ability scores: 4d6 drop lowest, standard array, or optimize for class
- Interactive play sheet: click any ability, save, or skill to roll a d20 with the right modifier; roll initiative; track hit points during play
- Searchable SRD rules reference (conditions, actions, combat, spellcasting, rests, equipment)
- Characters save to your browser (localStorage); no server, no account

**Run it**

Open `index.html` in any browser, or visit the GitHub Pages site for this repo. Plain HTML and JavaScript, no build step, no dependencies.
